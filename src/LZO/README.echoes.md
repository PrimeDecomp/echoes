# LZO 1.08 source subset

The source and supporting headers are unchanged files from Markus F. X. J.
Oberhumer's LZO 1.08 release (12 July 2002). This subset provides initialization,
pointer alignment and LZO1X decompression used by the G2ME01 binary.

Archive: https://distfiles.macports.org/lzo/lzo-1.08.tar.gz

SHA-256: `bcead46b0bd887c3987e977a0a7d4c547b0f70f926d45e253784137569f57b9a`

Public headers are in `include/LZO`. The original `README` and GPL license
(`COPYING`) are included here. The library uses the repository's C runtime
compiler settings; stream wrappers use the game library settings.
